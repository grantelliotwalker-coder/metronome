# Metronome

A single-file metronome that runs in the browser. Open `index.html` to use it.

- Tempo from 30 to 240 BPM (slider, +/- buttons, or tap tempo)
- 1-12 beats per bar with an accented first beat
- Subdivisions: eighths, triplets, sixteenths
- Pendulum animation synced to the audio clock
- Volume control
- Keyboard: Space starts/stops, Up/Down change tempo (Shift for steps of 10)
